# Genesis Route First — experimental safety pass

Device screenshots show monotonous wall/ground/grass chunks and blocked routes. The former stress test rewrote all unprotected cells, then learned three semantic terrain classes. Chunk stitching did not prove native movement after event protection.

This branch intentionally replaces destructive overworld generation with a conservative route-first pass. The original map supplies its traversability graph, complete authored art, elevations, ledges, connections, object/warp/coord/bg locations. Cities, caves, ocean routes and other map types are left exactly native. On General outdoor routes only, exact unblocked authored tall-grass metatiles with native tall-grass behavior may become the known normal grass metatile, retaining all non-ID bits. The mask derives from winding two-cell tracks and coherent 8-cell noise; isolated grass remains untouched. Old routes never become blocked by this pass. This is not a proof that all authored maps or scripted gates are reachable in every game state. No new walls or relocated trainers; no claim of new route topology. Existing 7-cell connected borders and event protection stay. One-bit changed-cell bitmap replaces large buffers and learned wall rules in this test; no GBAX requirement yet. Seed is fixed per layout for reproducibility. Fresh test save recommended because old destructive-generator saves/states may still contain stale terrain.

Next: generate an explicit graph of story anchors, port offsets, directional movement and capability-gated edges, then select authored multi-metatile modules (forest edges, cliff corners, water shores, road bends, bridges, clearings) compatible with the target tileset. Plan primary corridor, optional branches and landmarks before assigning vegetation. Flood-fill actual native movement with elevation/ledge/HM state, validate all required endpoints and compare progression reachability; reject invalid seeds, fall back to original map. Keep authored content until these constraints pass. GBAX will allow more complete route graph and temporary memory without stressing native EWRAM. Separate phase for caves/oceans. This pass is for visual and gameplay regression only.
