# Genesis Route Grammar v1 — experimental

Replace destructive independent terrain chunks on authored land routes with a template-first grammar. Preserve all original metatiles other than exact General Grass/TallGrass entries (same collision/elevation), including cliff faces, tree composites, ledges, water, bridges, paths and special tiles. Preserve event neighborhoods, seven-cell connection margins and arrival tile. Regional 6x6 interpolated value field modifies vegetation edges and clearings only inside compatible authored meadows. Keep substantial grass cores, narrow bare corridors, and original route-specific art. No newly generated collision or elevation changes; this does not repair pre-existing authored or scripted blocks. Ocean/cave generation temporarily disabled rather than applying unsafe generic tiles. Cities unchanged.

This is a safe first step, not full Hoenn Reborn: original geometry, route graph and map dimensions remain; seed is fixed test seed + layout ID. New geometry, explicit traversability graph (including elevation, ledges, HM/story gates), biome-specific motifs and persistent per-save seed are future GBAX work. Use a fresh test save; older experimental save states can contain generated terrain. No native GBAX dependency. Host regression checks 1024 seeds, determinism and exact collision/elevation preservation. ROM compile and device playtest required. No new static chunk buffers; only changed-cell bitset needed for saved map view reconciliation.
